# Goldengames RetroHub Pro — Native Title

This directory is the v0.2 native-title track.

The previous `native-ui/` SDL/bootstrap work is retained as diagnostic history and is not the target architecture for the final v0.2 release.

## First hardware milestone

The first title build must show an unmistakable GoldenGames frame rather than a plain background:

- GOLDENGAMES RETROHUB PRO
- build ID
- five carousel placeholders
- controller hint bar

Input will be added only after that presentation frame remains stable on PS5 firmware 5.10.

See [ARCHITECTURE.md](ARCHITECTURE.md).
