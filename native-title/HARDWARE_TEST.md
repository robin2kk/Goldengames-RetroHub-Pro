# PS5 5.10 hardware acceptance — Native Build 001

This build is a presentation/lifecycle gate, not the public v0.2 release.

## Install

Copy the complete `PPSA99202` directory from the test archive to:

`/data/homebrew/PPSA99202/`

Keep the directory structure intact. Launch **Goldengames RetroHub Pro** from the PS5 homebrew launcher/title environment.

## PASS

The television visibly shows all of these at the same time and the screen remains active:

- GOLDENGAMES RETROHUB PRO
- NATIVE TITLE - BUILD 001
- five clearly separated carousel cards
- RETROHUB
- LEFT RIGHT SELECT SYSTEM
- GOLDENGAMES V0.2

A plain blue/dark screen, notifications without the GoldenGames frame, or an immediate return to the PS5 menu is **not** a pass.

## Safety

The test does not contain or modify ROMs, BIOS, saves, history, or RetroArch configuration. It does not update firmware.

## Release gate

Do not publish/tag v0.2 from this build. Controller, scanning, content launch/return and firmware-5.10 hardware validation must pass before release.
